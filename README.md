# ai-assisted-compiler
AI-assisted compiler for syntax-error detection, explainable diagnostics, and code correction.

- **Frontend Website (React + Vite):** https://syntax-lab-omega.vercel.app/

- **API Health Check:** https://syntaxlab-z4da.onrender.com/api/health
- **Interactive API Documentation (Swagger):** https://syntaxlab-z4da.onrender.com/docs

## Deployment

- Frontend: Vercel
- Backend: Render
- API Framework: FastAPI
- Compiler: C++ with Flex and Bison
